# 专业实习智能平台 · 可运行原型 v0.2

在线演示：https://mortycrop-777.github.io/whu-internship-platform-demo/

静态前端原型，Markdown 排版依赖本地 `vendor/` 中随附的资源。可通过本地静态服务器预览；真实助手需要连接本地 Agent 服务。

当前为可交互原型，用于评审、演示和需求确认。真实账号、平台数据库、对象存储和生产 API 尚未接入；除通过本地 Agent 服务保存的学生助手会话外，演示数据刷新后会恢复初始状态。

无后端时可直接使用 `?previewRole=teacher`、`?previewRole=student` 或 `?previewRole=enterprise` 进入角色原型。公告发布内容会保存在当前浏览器的 `localStorage`，方便在教师端与学生端预览之间查看同一份公告。

本地学生助手联调：使用 Agent 仓库的 `feat/web-integration` 工作区运行 `npm run web` 并将 `AGENT_WEB_ROOT` 指向本目录，从该服务输出的本机地址访问（默认端口 18766；本次预览配置为 18765）。此时学生助手可连接本机 Agent，其他页面仍为演示数据。直接打开文件或使用静态服务时，学生助手不会连接真实 Agent。详细配置与单用户限制见 Agent 仓库的 `docs/网页本地联调.md`。

## 设计规范

界面采用冷灰蓝画布、白色内容模块和浅蓝主操作层的分层体系。颜色、阴影、间距、表格和深浅主题规则见 `DESIGN_SYSTEM.md`。

## 可交互内容

- 平台账号登录；正式教师/企业账号接入前，可用 `?previewRole=teacher` 或 `?previewRole=enterprise` 预览对应端。
- 侧栏在三种角色之间切换，当前页高亮；左下角可收起/展开，收起后仅保留图标并记住状态，移动端自动收起。
- 学生实习助手：连接本地 Agent 后支持按发生顺序显示文字和可折叠的处理步骤、追问及历史会话。输入区默认单行布局（左「+」、中输入框、右思考强度与发送）；输入换行或自动折行时切换为多行布局（输入框占整行、工具行在下方），多行达到 8 行或 300 字后右上角出现展开按钮，可切换更高编辑区，Esc 收起；有附件时直接进入多行布局。生成状态保持在输入区上方。用户要求新建 DOCX/PDF 时可直接生成，最终交付文件位于回复末尾；PDF 可预览。旧会话的确认记录仍可查看。思考仅展示状态，不显示模型推理文本。
- 学生实习助手 · 文件上传：输入区「+」按钮、拖拽到聊天区、粘贴文件均可添加 Word（.docx）、PDF、PNG/JPG/JPEG/WebP 图片；选文件后立即上传，待发送区以紧凑 tray 显示分色文件图标（图片为绿色图片图标）、中部省略且保留扩展名的文件名与上传进度，失败可重试或移除；粘贴截图没有扩展名时按 MIME 自动补名（如「粘贴图片-时间戳-1.png」）。文件较多时 tray 内部滚动（约 3–4 行高度），2 个及以上时显示数量与总大小并提供清空。上传中不能发送消息，达到每会话 20 个上限后「+」按钮会禁用并提示。发送成功后附件以轻量标签展示在用户消息上方，历史会话恢复时同样展示。限额：图片单张 20MB、Word/PDF 单文件 50MB、每会话最多 20 个（单轮上限等于会话剩余额度，不再有独立的每轮 3 个），超限会给出中文提示；会话总字节 500MB 由服务端强制，服务端 409 的错误文案会以轻提示展示。上传件（含图片）仅显示文件名与大小，不提供下载或预览，模型可读取图片内容。
- 学生实习助手 · 空态推荐：输入框下方一行极简胶囊（准备实习 / 整理经历 / 探索方向 / 写周报 / 去填志愿 / 看实习记录），整行居中、无彩色、无卡片、无副标题，静止完全透明，hover/键盘焦点才出现浅灰胶囊；行尾 32px 圆形「换一批」图标按钮，轮换为轻量发牌（旧胶囊左移淡出、新胶囊右侧回弹错峰）；桌面精细指针下保留胶囊轻微跟手倾斜供对比（≤6°），支持跨板块跳转、点击只填入输入框不发送、键盘操作、移动端自动换行与暗色适配。推荐项 schema 与 `GET /api/suggestions` 接口草案见 `docs/suggestions-contract.md`。
- 历史对话从右侧抽屉打开，支持按标题搜索、按最近更新时间分组，以及打开、重命名和删除会话；每条会话标题下显示最多 2 个生成的产物（点击即可下载，超出显示 +N），帮助回忆历史产出；只有上传件、没有产物的会话不显示。
- 学生实习助手 · 设置页：左下角齿轮进入独立设置页面（左分类、右内容，顶部「← 返回」回到进入前页面）；「实习助手」分类显示个人记忆状态（已开启 · N 条 / 未开启 / 读取失败）并可「管理」打开记忆面板（查看/编辑/删除/清空，是否可用取决于后端 `AGENT_MEMORY_ENABLED`）；「通用」分类含外观切换与退出登录。移动端分类变为横向 Tab，不再有「上下文用量」入口。
- 学生实习助手 · 记忆提示：助手在本轮写入或更新个人记忆时，回复正文下方会显示一条低饱和「已记住：… / 已更新记忆：…」提示，点「查看」可打开个人记忆面板；提示在刷新历史后仍会回放显示。
- 学生实习助手 · 对话内记忆管理：可直接在对话里让助手查看/修改/删除个人记忆，修改与删除会先弹出确认（确认修改/确认删除 + 取消），确认后处理步骤会显示对应操作并继续正常回复。本机已用合成资料验证：一轮写入记忆后，新会话在无历史时准确召回，设置内编辑/删除/清空生效。
- 公告栏：教师直接点击侧栏公告栏编辑并发布标题与正文；学生点击同一公告栏查看完整内容。当前仅为前端会话内演示，不包含接收人、已确认统计和后端持久化。
- 学生志愿：填写并提交志愿，状态变为审核中；右上角可下载可打印的纸质版志愿表 PDF。
- 学生实习记录：16 周实习日历，按天记录上班/下班时间、工作量与心情；周报页顶部为 1–16 周步进条，选中周后展示本周小结卡（深色卡面、按本周打卡数据生成的标语与工时 / 平均上下班 / 心情，可保存 PNG 或复制分享文案）与提交、教师评价两栏；周报以 Word/PDF 上传（可附备注），教师评分采用 100 分制；实习作品按「书架」陈列成书封卡（类型封面 + 周次 + 文件名），可在页头切换按类型 / 按时间排序（新增作品按钮位于页头工具栏，与生成实习总结并列），书封与周小结卡带跟随指针的按压 / 倾斜悬停效果，点击书封弹出详情，可生成实习总结（衔接实习助手）。
- 学生个人信息：填写实习单位、导师、居住地址与紧急联系人，同步到教师实习卡片。
- 学生揭榜：点击岗位卡查看职责与任职要求；点击立即揭榜后必须上传 PDF 简历，确认提交后岗位才变为已揭榜。
- 教师学生台账：按学生姓名搜索，按班级、实习单位、实习状态组合筛选，并查看实习档案卡和关键联系信息。
- 教师数据看板：批量导入学号、姓名、身份证号；预览校验后自动创建账号，并按有效导入人数更新应实习人数。
- 教师周报评价：列表展示本周得分（百分制）；选择等级和附加标签，系统按规则自动计分（满分 100），结果同步到学生历史周报。
- 企业岗位：发布岗位、结束岗位。
- 企业评分：打开评分弹窗、提交评分、切换待评分/已评分。
- 企业揭榜管理：查看学生资料与 PDF 简历，支持在线打开和下载，并完成通过 / 拒绝申请。

## 多用户任务测试

学生助手通过平台后端的任务接口提交对话并订阅事件；排队、等待回答、停止及网络重连由服务端任务状态驱动。刷新会按任务事件与保存的历史边界重建当前轮，避免重复显示；用户切换或其他业务页面仍以当前平台能力为准。平台测试身份、其他板块数据、生产安全和多机部署的边界见后端 README。

## 说明

- 实习助手会话及生成文件保存在本机；其他页面使用演示数据。
- 上传文件保存在本地 Agent 服务的工作区中，随消息交给当前会话使用；删除会话时由服务端清理对应上传件，前端无需单独清理。上传界面只展示名称与大小，不提供下载或预览。
- 文件上传依赖本地 Agent 服务的 `/api/uploads` 接口：直接打开文件或只用静态服务器时上传会提示服务未连接；新会话使用前端生成的 `uploadGroupId` 作为工作区标识，拿到服务端会话 ID 后改用该会话。
- 截图在 `screens/` 目录。
- 除本地 Agent 服务外，正式平台后端和真实账号均未接入。

实习助手的回复排版使用本地随附的 Marked 18.1.2 和 DOMPurify 3.4.17（位于 `vendor/`，许可证同目录），支持流式 Markdown 渲染并对生成的 HTML 做清理。更新这些依赖时请同步更新许可证和验证渲染安全性。
