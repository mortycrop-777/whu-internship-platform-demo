# 专业实习智能平台 · 可运行原型 v0.2

单文件原型，无外部依赖。直接双击 `index.html` 即可运行，也可以用本地静态服务器打开。

## 页面路由

- `#/login` 登录
- `#/student/chat` 学生 · 经验问答
- `#/student/volunteer` 学生 · 志愿填报
- `#/student/internship` 学生 · 实习记录
- `#/student/profile` 学生 · 个人信息
- `#/student/challenges` 学生 · 揭榜挂帅
- `#/teacher/dashboard` 教师 · 问题看板
- `#/teacher/students` 教师 · 学生台账
- `#/teacher/reports` 教师 · 周报评价
- `#/enterprise/jobs` 企业 · 发布岗位
- `#/enterprise/scoring` 企业 · 实习评分
- `#/enterprise/applications` 企业 · 揭榜管理

## 可交互内容

- 登录页选择学生 / 教师 / 企业身份，支持一键体验。
- 侧栏在三种角色之间切换，当前页高亮。
- 学生问答：快捷标签、提示词、历史对话下拉、发送问题、语料出处卡片、拒答提示。
- 学生问答 · 实习记录模式：在对话框内整理项目、成果和技能，不跳转到实习记录页。
- 学生志愿：填写并提交志愿，状态变为审核中；右上角可下载可打印的纸质版志愿表 PDF。
- 学生实习记录：20 周实习周期、富文本周报、图片与附件、教师评价查看。
- 学生个人信息：填写实习单位、导师、居住地址与紧急联系人，同步到教师实习卡片。
- 学生揭榜：点击岗位卡查看职责与任职要求；点击立即揭榜后必须上传 PDF 简历，确认提交后岗位才变为已揭榜。
- 教师学生台账：按学生姓名搜索，按班级、实习单位、实习状态组合筛选，并查看实习档案卡和关键联系信息。
- 教师数据看板：批量导入学号、姓名、身份证号；预览校验后自动创建账号，并按有效导入人数更新应实习人数。
- 教师周报评价：列表展示本周得分；选择等级和附加标签，系统按规则自动计分，结果同步到学生历史周报。
- 企业岗位：发布岗位、结束岗位。
- 企业评分：打开评分弹窗、提交评分、切换待评分/已评分。
- 企业揭榜管理：查看学生资料与 PDF 简历，支持在线打开和下载，并完成通过 / 拒绝申请。
